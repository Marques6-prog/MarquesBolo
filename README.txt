Marque's Bolos
==============

A responsive static bakery website. Open index.html in a browser or serve this
folder with a local web server.

Project files:
- assets/css/style.css: site styles
- assets/js/site.js: mobile navigation and current-year footer
- assets/images/Marques_bolo.jfif: supplied bakery logo

Source and asset notes:
The original project included the Shahala news template by FreeHTML5.co. This
redesign preserves that source acknowledgement. Existing vendor libraries,
fonts, and image assets remain in the project; review their individual license
notices before redistributing them.
